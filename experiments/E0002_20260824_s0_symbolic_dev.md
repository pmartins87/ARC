## Result

S0 fitted **zero exact demonstration-consistent hypotheses across all 60 evaluation-development tasks** under its current DSL (D4 transforms, crop, connected-component selection, integer cell scaling, global color remapping, constant output). Consequently it solved 0/82 test outputs at pass@1 and pass@2.

The result is a useful negative baseline rather than a candidate competition component. It demonstrates that the calibrated ARC-AGI-2 evaluation distribution is not covered by shallow global transforms or one-step object extraction.

## Aggregate training-demonstration profile

The profiler consulted only training demonstrations for the frozen 60-task development split; test outputs were not used.

- 60 tasks / 178 train pairs.
- 39/60 tasks have identical input/output dimensions across every demonstration.
- 17/60 consistently shrink output area; only 1/60 consistently enlarges it.
- 52/60 always use an output color set that is a subset of the input colors.
- 32/60 preserve the exact color set in every demonstration.
- 22/60 consistently remove at least one input color.
- 7/60 consistently introduce a new color.
- Shape relation by task: 39 same/same; 12 down/down; 6 mixed; 3 other.

These statistics point toward contextual selection, relational reasoning, compositional transformations and local rule application rather than a need to merely enumerate more D4/crop variants.

## Decision

**REJECT S0 as a serious standalone symbolic baseline/final solver.** Keep it as a regression and diagnostic instrument.

M1 stop rule: do not spend the remaining baseline time expanding a naive primitive library by trial and error. The next symbolic reference must come from a materially stronger published program-synthesis/MDL family or be marked PARTIAL at the M1 deadline. Original architecture work remains reserved for later milestones after the competitive neural baseline/error map is available.
